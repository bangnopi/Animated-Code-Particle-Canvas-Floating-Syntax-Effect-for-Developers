# Animated-Code-Particle-Canvas-Floating-Syntax-Effect-for-Developers
Dibangun menggunakan HTML5 Canvas murni tanpa library tambahan, efek ini sangat ringan dan bisa dijadikan latar belakang tematik untuk website bertema teknologi, portfolio developer, landing page SaaS, atau dashboard proyek coding.

🧩 Description:

Script ini menampilkan efek visual interaktif berupa potongan-potongan kode yang melayang bebas di layar, menyerupai partikel bercahaya bertema developer environment. Setiap partikel menampilkan potongan sintaks dari berbagai bahasa (JavaScript, PHP, SQL, Bash, JSON, CSS, HTML, hingga Mikrotik command) dengan efek “mengetik” dinamis dan arah gerak acak dari tepi layar.

Dibangun menggunakan HTML5 Canvas murni tanpa library tambahan, efek ini sangat ringan dan bisa dijadikan latar belakang tematik untuk website bertema teknologi, portfolio developer, landing page SaaS, atau dashboard proyek coding.

Beberapa fitur utama:

✨ Partikel teks “kode” bergerak halus dengan efek ketik bertahap.

🎛️ Dukungan auto-resize menggunakan ResizeObserver dan devicePixelRatio.

💡 Multi-layer particle system (dua kanvas dengan gaya dan perilaku berbeda).

🌐 Mendukung semua resolusi dan layar mobile (memperhitungkan safe-area iOS).

🧠 Kumpulan snippet mencakup JavaScript, PHP, SQL, Bash, JSON, CSS, HTML, hingga perintah terminal khas devops dan jaringan.

Script ini cocok buat lo yang ingin menambah sentuhan “AI developer vibe” di halaman web tanpa plugin berat.
Cukup salin kode ke dalam <body> dan pastikan ada elemen #particle-zone sebagai pembungkusnya.
